# Generate AI Context

Use the prompt in `prompts/generate-ai-context.prompt.md` from the repository root.

Update:

- `project-analysis.md`
- `quick-context.md`
- `ai-entry.md`

Rules:

- `project-analysis.md` should contain the deeper architecture and repository analysis.
- `quick-context.md` should stay compact and be derived from `project-analysis.md`.
- `ai-entry.md` should tell future AI agents what to read first.
- Avoid scanning unrelated generated files, build artifacts, dependency folders, or secrets.
- Keep the files concise, accurate, and useful for future AI work.
